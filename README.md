# Yangi alifbo — Özbek matn konvertori

https://vinchezko.github.io/yangi-alifbo/

Hozirgi yozuvdagi özbek matnini yangi alifboga bir zumda almaştiradigan veb-sayt. Matn brauzerning özida işlanadi, server yoki hisob (akkaunt) kerak emas.

## Almashtirish qoidalari

| Eski yozuv | Yangi yozuv | Misol |
|:---:|:---:|:---|
| Sh, sh | Ş, ş | shahar → şahar |
| Ch, ch | Ç, ç | choy → çoy |
| Oʻ, oʻ | Ö, ö | oʻqituvchi → öqituvçi |
| Gʻ, gʻ | Ğ, ğ | gʻoya → ğoya |

Alifboning qolgan harflari özgarmaydi.

## Nimalarga tegilmaydi
- Tutuq belgisi: taʼlim, maʼno kabi sözlardagi apostrof öz holiça qoladi.
- Keng tarqalgan ingliz sözlari (masalan, school, check, English) özgarmaydi.
- Havolalar, sayt nomlari, elektron poçta manzillari, @nom va #teg özgarmaydi.
- Apostrofning barça körinişlari tanib olinadi.

## Imkoniyatlar
- Almaşgan sözlar sariq rangda körsatiladi, sözni bosib eski yozuvga qaytariş mumkin.
- «Hammasini almaştiriş» va «Hammasini qaytariş» tugmalari.
- Matnni nusxalaş.
- Matn statistikasi: söz, gap va belgi soni, öqiş vaqti, takrorlanmas sözlar.
- Almaşgan harflar (Ş, Ç, Ö, Ğ) sanoği.
- Kunduzgi va tungi mavzu.
- Sahifani aylantirganda işlaydigan qisqa yöriqnoma va jonli namunalar.

## Maxfiylik
Kiritilgan matn heç qayerga yuborilmaydi va saqlanmaydi. Faqat tanlangan mavzu (kunduzgi yoki tungi) brauzerning mahalliy xotirasida eslab qolinadi.

## Texnik maʼlumot
- Bitta `index.html` fayl: HTML, CSS va oddiy JavaScript, tashqi kutubxonalarsiz.
- Shriftlar: Fraunces, Newsreader, Instrument Sans (Google Fonts).

## Çeklovlar
- Ingliz sözlari röyxati qölda tuzilgan, şuning uçun unda yöq söz almaşib ketişi mumkin. Bunday sözni bosib eskisiga qaytariş mumkin.
- Harf oldidan apostrof kelgan har bir «o» va «g» almaştiriladi. Kamdan-kam hollarda bu tutuq belgisi bölişi mumkin, natijani tekşirib çiqing.
