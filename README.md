# Yangi alifbo — Özbek matn konvertori

Hozirgi yozuvdagi Özbek matnini yangi alifboga (Sh→Ş, Ch→Ç, Oʻ→Ö, Gʻ→Ğ) almaştiradi.
Bitta `index.html` fayl, hech qanday server yoki kutubxona kerak emas.

## GitHub Pages orqali chiqarish
1. Yangi repozitoriy yarating va shu fayllarni yuklang (`index.html`, `.nojekyll`, `README.md`).
2. Settings → Pages → Branch: `main` / root → Save.
3. Bir daqiqadan keyin sayt `https://<login>.github.io/<repozitoriy>/` manzilida ochiladi.
